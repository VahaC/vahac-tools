WireGuard Config Generator

Plan a WireGuard server and its clients in one go: the server's wg0.conf with a [Peer] block per client, and a ready .conf file and QR code for every phone, laptop or router. Keys are created in your browser and never leave this page.

!

Every client config and QR code contains that device's private key, and the server's wg0.conf contains the server's. Anyone who gets one can connect as that device. Scan QR codes straight from this screen, move files over a channel you trust, and delete downloaded copies once they are imported.
