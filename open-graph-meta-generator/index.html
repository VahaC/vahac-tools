Open Graph Meta Tag Generator and Checker

Build the <title>, meta description, canonical link, Open Graph and X (Twitter) card tags for a page, check the share image against the sizes Meta, X and LinkedIn document, and see an approximate preview. Or paste a page's <head> and get every tag listed with the missing, duplicate and conflicting ones, each with the fix and its source. Nothing is fetched or sent anywhere unless you ask this page to load an image URL.

Page

title · description · canonical

Meta asks for the title "without any branding such as your site name"; the site name has its own tag below. Leave this empty to reuse the page title.

Written as the meta description and og:description. Google sets no length limit and shortens snippets to fit the screen; ogp.me suggests one to two sentences, Meta two to four.

The full address of the page, written as <link rel="canonical"> and og:url. Leave out tracking parameters such as utm_source.

Locales use the language_TERRITORY form of ogp.me, such as en_US; leave the locale empty and consumers assume en_US.

Content type

og:type

ogp.me treats any page without a type as website, and so does Meta. Choose article for blog posts and news; it adds the article: properties below.

ISO 8601, as ogp.me requires: a date such as 2026-10-27, or a date and time with a time zone offset such as +02:00 or Z. "Now" fills in this device's current time and offset.

ogp.me types this as a profile array, so the value is the URL of an author page. Separate several with commas.

Share image

og:image

Describe what is in the image, not a caption (ogp.me). X reads it as the image's alt text when twitter:image:alt is not set.

Check the image

Choose the image file from your computer to read its pixel size, file size and type and compare them with what each platform documents. The file stays on your device.

"Load the image URL" makes your browser request the image URL above from its server, which sees your IP address as with any visit. It reads only the pixel size; the file size and type would need a download this page does not make. Nothing is requested until you press it.

X (Twitter) card

twitter:card

Facebook app ID (optional)

fb:app_id

Meta's guide asks for it only to use Facebook Insights, its traffic analytics. Find it in the App Dashboard.

    Good to know
    
      
      
        
    • X reads Open Graph. When a twitter: tag is missing, X uses og:title, og:description, og:image and og:image:alt instead, and its parser also accepts the property attribute of Open Graph markup. So a page needs little more than twitter:card on top of its og: tags. Open Graph tags use property=, X tags name=.
      • 
        
    • First or last wins. ogp.me gives the first of several values preference, and repeated og:image tags are a list with the first preferred. For twitter:card, X uses the last one on the page.
      • 
        
    • Google writes its own title links and snippets. It publishes no character limit for either and shortens them to fit the device; og:title is one of the sources it may use for a title link.
      • 
        
    • Crawlers must reach the page and the image. X's crawler follows robots.txt, so a blocked page gets no card and a blocked image no picture. Meta reads Open Graph tags only within the first 1 MB of the page, and LinkedIn notes that a site blocking it or an image in a protected directory stops the preview.
      • 
        
    • Not covered: JSON-LD structured data, oEmbed, X app and player cards, and video and audio tags beyond URL checks. Previews in chat apps such as Slack, Discord, Telegram and WhatsApp are not modelled, because this tool only applies rules a platform documents.
