Supported flags & fields

Handles the common flags you'll actually run into: -p/--publish, -v/--volume, -e/--env, --env-file, --name, --network, --restart, -u/--user, -w/--workdir, --entrypoint, --label, --cap-add/--cap-drop, --dns, --add-host, --device, -m/--memory, --cpus, --health-*, --log-driver/--log-opt, --ulimit and more. Anything that has no equivalent on the other side is flagged as a warning instead of silently dropped. Compose files with several services convert into several docker run commands (and vice versa) — separate multiple docker run commands with a blank line to convert them together.

Built by VahaC — 100% client-side, no data sent anywhere.
