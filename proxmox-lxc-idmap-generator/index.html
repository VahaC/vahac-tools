Proxmox LXC idmap Generator

Let an unprivileged container read and write a host folder as a real host user. Enter which container UIDs and GIDs should map to which host IDs, and get the lxc.idmap lines for /etc/pve/lxc/<ID>.conf, the /etc/subuid and /etc/subgid entries, the bind mount line and the chown command. Everything runs in your browser.

Container

Its config file is /etc/pve/lxc/<CTID>.conf. Use this on an unprivileged container (unprivileged: 1).

Advanced host base and range size

Proxmox maps unprivileged containers as u 0 100000 65536 and g 0 100000 65536: container ID 0–65535 becomes host ID 100000–165535. Change these only if you already run a different range.
