cURL to Code Converter

Paste a curl command from API docs, a README or your browser's Copy as cURL. The tool reads it the way your shell and curl would, then writes the same request as fetch(), Python requests or Node.js code. Options that cannot be carried over are listed, not silently dropped. Nothing leaves your browser.
