Unique local /48 generator

RFC 4193

A unique local address (ULA) prefix is your own private IPv6 space for a LAN, a lab or a VPN, the IPv6 counterpart of 192.168.x.x. It starts with fd, followed by a 40-bit Global ID that must be random, so that two networks you connect later are very unlikely to clash. The ID comes from your browser's crypto.getRandomValues and is never stored or sent.

RFC 4193 §3.2.2 suggests hashing the time and an EUI-64 with SHA-1; any good random source meets §3.2.1 just as well. Unique local addresses are not routed on the Internet, so you still need a global prefix from your ISP for Internet access.

Interface ID from a MAC address

modified EUI-64

Most desktop and mobile systems no longer build their addresses this way: they use temporary addresses for outgoing connections (RFC 8981) and a stable ID that does not reveal the MAC (RFC 7217, recommended by RFC 8064). EUI-64 still shows up on routers, embedded devices and in link-local addresses. The MAC stays in this page and never goes into the link.

Good to know

  • Every LAN gets a /64. Interface IDs are 64 bits (RFC 4291 §2.5.1), and SLAAC ignores a prefix whose length plus the interface ID is not 128 (RFC 4862 §5.5.3). RFC 7421 explains what breaks with longer LAN prefixes.
  • Sites get a /48 or a /56. RIPE-690 recommends a /48 per end site, or a /56 for residential customers, and calls anything longer than /56 strongly discouraged. A /56 is 256 LANs, a /48 is 65,536.
  • Stay on nibble boundaries. Each hex digit is 4 bits. Prefix lengths that are multiples of 4 keep subnet numbers readable and give each subnet its own ip6.arpa zone (RFC 3596 §2.5, RIPE-690 §4.2).
  • No broadcast, and /127 for router links. IPv6 has no broadcast address. The all-zero interface ID is the Subnet-Router anycast address (RFC 4291 §2.6.1). Point-to-point links between routers may use a /127, with both addresses in use (RFC 6164).
  • Zone IDs stay on your host. fe80::1%eth0 tells your own system which interface to use (RFC 4007 §11). Browsers do not accept zone IDs in URLs: RFC 9844 (2025) withdrew the URL syntax of RFC 6874 and asks user interfaces to accept them instead.
  • Writing addresses down. RFC 5952 fixes one text form: lowercase, no leading zeros, :: only for the longest run of two or more zero groups. Mixed notation (::ffff:192.0.2.1) is used only for the well-known IPv4-embedding prefixes.
