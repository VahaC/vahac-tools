UTM Campaign URL Builder

Tag any link so Google Analytics shows which newsletter, post, ad or flyer brought each visitor. Pick a preset, check which GA4 channel the visits will land in, then copy the link or download a QR code for print. Everything runs in your browser.

Link details

The page visitors should land on. Paste an already tagged link to edit its tags.

utm_source — where the visit comes from

utm_medium — the kind of channel

utm_campaign — the promotion, product or slogan

utm_content — tells apart links or ads in one campaign

utm_term — the paid search keyword

More GA4 parameters campaign ID, source platform, creative format, tactic

utm_id — recommended if you import cost data into GA4

utm_source_platform — the platform that buys or manages the traffic

utm_creative_format — not reported in GA4 yet

utm_marketing_tactic — not reported in GA4 yet
